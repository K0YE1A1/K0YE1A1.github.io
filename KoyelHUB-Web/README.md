> **Современная браузерная панель управления (Web Dashboard)** для Discord-бота **KoyelAI** и системы безопасности сервера **K0YE1 Controll**.
> Позволяет администраторам управлять ботом, просматривать логи в реальном времени через WebSocket, настраивать верификацию, тикеты, публиковать новости и анализировать историю прямо в браузере.

---

## ✨ Ключевые возможности

### 🌐 1. Браузерная панель (Web Panel)
* **🔐 Двухуровневая система доступа по паролям:**
  * 👑 **Создатель (`Kimzar60`):** Полный неограниченный доступ ко всем функциям, просмотру, редактированию и шифрованию токенов в сейф.
  * 🛡️ **Администратор (`Artem255`):** Управление ботом, сервером, тикетами, публикация новостей, аудит и история. Чужие платные токены API надежно замаскированы звездочками.
* **🔒 Защищенный сейф (AES Encryption Vault):**
  * Файл `Api_key.enc` зашифрован алгоритмом AES-128/Fernet. Даже если репозиторий окажется на GitHub, никто без пароля создателя не сможет расшифровать ваши API ключи и токен Discord!
  * Кнопка в веб-панели и утилита `vault.py` позволяют в один клик удалить открытый `Api_key.txt` перед выгрузкой в сеть.
* **📊 Живой терминал:** Вывод логов Discord-бота в реальном времени по WebSocket с автопрокруткой, фильтрацией и кнопкой копирования.
* **⚡ Управление в один клик:** Кнопки запуска, остановки, мягкого перезапуска бота и экстренной блокировки `/block`.
* **💖 Баланс и расценки:** Карточка мониторинга баланса (~90 ₽) и стоимости API (текст, фото 1080P, озвучка Voice AI).

### 🛡️ 2. K0YE1 Controll (Сервер & Модерация)
* **🖱️ Верификация участников (Капча как в Carl-bot):**
  * Очищает канал `#верефикация`, публикует правила и красивую кнопку «Аутентификация».
  * Автоматически выдает роль `@Верифицирован` и отправляет аудит в `#логи-koyel-ai`.
* **💬 Отправка сообщений в любой канал:**
  * Отправка чистого текста или брендированных Discord Embed карточек от имени и с аватаркой бота.
* **📩 Koyel Tickets (Тикет-система):**
  * Создание панели обращений с настраиваемой анкетой (Тема, Описание, Доп. инфо).
  * Автоматическое создание закрытых каналов между пользователем и админами.
* **📰 Koyel News:**
  * Автоматическая генерация игровых новостей (Roblox / a Desert и др.) через нейросеть **GPT-6 Luna AI**.
  * Предпросмотр, редактирование и мгновенная публикация в `#новости`.
* **🛡️ Фулл-Аудит и Модерация (как Akemi):**
  * Мониторинг удалений и редактирований сообщений.
  * Защита от спама (паузы 3 сек) и Discord-инвайтов.
  * Лимит матов: удаление сообщений, содержащих более 10 матерных слов, с публикацией очищенной версии.

### 📈 3. Статистика и Лидерборды
* Детальный учет затраченных токенов (Prompt, Completion, Total, Requests).
* Топ самых активных пользователей по текстовым запросам, генерациям картинок и вызовам **Voice AI**.

### 📁 4. История чатов (Chat History)
* Встроенный браузерный просмотрщик сохраненных локальных логов чатов по каналам и датам.

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/ваш-логин/KoyelHUB-Web.git
cd KoyelHUB-Web
```

### 2. Настройка конфигурации
Скопируйте шаблон `Api_key.example.txt` в `Api_key.txt`:
```bash
cp Api_key.example.txt Api_key.txt
```
Откройте `Api_key.txt` и укажите:
* `OPENAI_API_KEY` — ключ API (AITunnel или OpenAI).
* `DISCORD_BOT_TOKEN` — токен вашего Discord бота.
* `ADMIN_PASSWORD` — желаемый пароль для входа в веб-панель (по умолчанию `05122013`).

### 3. Запуск веб-панели (1 клик на Windows)
Просто запустите файл:
```bat
RUN_WEB_PANEL.bat
```
Скрипт автоматически установит зависимости, запустит локальный веб-сервер и откроет панель в браузере по адресу:
👉 **`http://localhost:5000`**

*(Для ручного запуска: `python web_panel.py`)*

## 🔒 Безопасность

* Файл `Api_key.txt` с вашими токенами и базой данных внесен в `.gitignore` и **никогда** не попадет в открытый репозиторий GitHub.
* Все эндпоинты API защищены сессионным Bearer-токеном после ввода пароля администратора.
* Команда экстренной блокировки `/block` в Discord и кнопка в веб-панели позволяют моментально заморозить ответы бота.
